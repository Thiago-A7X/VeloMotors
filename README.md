# VeloMotors (seu sonho sobre rodas) 🚗🏍️

## Sobre o projeto

O VeloMotors é um projeto desenvolvido para a faculdade, no curso de Análise e Desenvolvimento de Sistemas.

A ideia do sistema é facilitar o cadastro e o gerenciamento de veículos, incluindo carros e motos, organizando informações sobre marcas, modelos e veículos.

## Tecnologias utilizadas

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Maven

## Banco de dados

O projeto utiliza o MySQL para armazenar as informações.

O banco de dados utilizado tem o nome `velomotors`.

## Organização do projeto

O código Java está separado em algumas pastas:

- **Controller:** responsável pelas requisições do sistema.
- **Model:** contém as classes que representam os dados.
- **Repository:** faz a comunicação com o banco de dados.
- **Service:** contém a parte das regras do sistema.

O frontend possui os arquivos HTML, CSS e JavaScript.

## Como executar

1. Ter o Java e o MySQL instalados.
2. Criar o banco de dados `velomotors`.
3. Configurar o arquivo `application.properties` com os dados do MySQL.
4. Abrir o projeto no IntelliJ IDEA.
5. Executar a classe `VeloMotorsApplication`.
